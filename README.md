# Yunho Jo — Academic personal website

Website: https://ubbbin.github.io/

## Edit the website

- Edit `index.html` to change profile text, research interests, publications, patents, and projects.
- Upload images to `assets/` and update their `src` paths in `index.html`.
- Publications are grouped into Journals, International Conferences, and Domestic Conferences.
- The first two publications marked `data-featured` appear on the home page.
- Save changes to the `main` branch. GitHub Pages automatically publishes the updated website; the address stays the same.
- Changes made only to local files must also be uploaded or pushed to this repository.

Publication, patent, and project entries currently contain clearly marked template examples.
